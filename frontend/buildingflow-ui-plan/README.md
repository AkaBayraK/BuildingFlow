# BuildingFlow UI Modernizasyonu

Bu paket Claude Code veya Codex ile mevcut Next.js + TypeScript frontend ve .NET backend projesini aşamalı olarak modernize etmek içindir.

## Çalıştırma
1. Paket içindeki `AGENTS.md`, `MASTER_PROMPT.md` ve `PHASES.md` dosyalarını frontend projesinin köküne kopyalayın.
2. Claude Code: `claude` açıp `MASTER_PROMPT.md dosyasını oku ve yalnızca Aşama 01'i uygula.` yazın.
3. Codex: `codex` açıp aynı talimatı verin.
4. Her aşamada çıktı ve test sonuçlarını kontrol edin. Sonraki aşamayı ayrıca onaylayın.

Kod otomatik olarak burada uygulanmadı; ajan kendi çalışma ortamınızda mevcut repoyu inceleyecektir.
